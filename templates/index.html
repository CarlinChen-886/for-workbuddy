使用说明书

本工具把你上传的商品主图和你选的日期，按统一口径自动提取结构化信息，生成对比 Excel。

① 上传

  • 方式一：把图片拖入中央虚线框。
  • 方式二：⌘/Ctrl + V 直接从剪贴板粘贴图片（可多次粘贴）。
  • 方式三：点击中央框，多选图片一次性上传。

② 分批次选日期

  • 同一批次（图1为今年、图2为去年；或不同活动）可以分别添加批次。
  • 每个批次一个统一日期 → 该批次里所有图默认使用这个日期。
  • 单张图也可单独改自己的日期（覆盖批次默认值）。

③ 运行

  • 点「运行并识别」，后端自动 OCR 读取主图文字，再按规则解析出：主品、赠品明细、到手价/优惠文案、活动周期 logo。
  • 跳转结果页，每张图可对解析结果手动校正（如 OCR 漏字、错字、需补值）。新增：商家货补（直播间/自播间）、商家券（店铺券/会员券）、购物金/储值权益均可逐条录入，并标注来源与是否计入折扣。
  • 页面底部自动汇总分项合计与主图宣称总减免差异，方便校验。
  • 点底部「下载 Excel」即按你校对的版本生成对比表（17 列：含商家优惠层 L/M/N + 平台券层 O/P/Q、原图嵌 A 列；不同品牌自动分 Sheet，单品牌则单 Sheet「对比表」）。Excel 中透传所有优惠明细字段。

④ 商家货补 / 商家券 / 购物金录入

  • 商家货补：直播间/自播间货补，多文案统一（如"主播直降补贴""直播间限时补贴"均归为货补），可添加多条分别录入。
  • 商家券：店铺券、会员券、直播券、商家红包等，与平台券区分。
  • 购物金/储值：充值膨胀类权益（如充500得550），完全不计入折扣（预充值非减免，规则10），仅作信息展示。
  • 每条录入名称、金额、门槛、来源（主图 / OCR / 人工补充）、是否计入折扣。主图没有且未人工填写的 → 不导出。

⑤ OCR 自动能识别 vs 不能识别

能识别：主品名 + 规格 ml、赠品名 + ml（赠：…+…+…）、「会员加赠」类的工具赠品、限时直降/到手价 ¥X；大促图还能识别平台券名与立减总额（如 88VIP专享券 / 美妆加补券 / 领券立减¥250）。

不识别（结果页会标 [需补充]）：主品官方原价（电商搜索才有的，图片通常不印刷）、优惠扣减金额（图片只印到手价）、赠品估值（需 ml × 正装单 ml 官方价）、平台券具体金额拆分（图里常只印合计立减额，券种拆分按当期平台规则补）。商家货补、商家券、购物金默认全部人工补充，OCR 不自动识别。

⑥ 页面切换

顶部「重新上传」可随时清空，回到 Page1 上传新一批图。
